# JISUNG 92

업무와 일상을 조금 편하게 만드는 개인 작업실입니다. 정적 페이지는 GitHub Pages에서 실행되고, 방명록 데이터와 인증은 Supabase를 사용합니다.

## 주요 경로

- `/` — 개인 홈페이지
- `/about/` — 소개
- `/notes/` — 기록과 메모
- `/guestbook/` — 방명록
- `/changelog/` — 변경 기록
- `/tools/` — 업무·일상 도구
- `/assets/` — 공통 스타일, 스크립트, 이미지
- `/data/` — 공개 정적 데이터
- `/supabase/migrations/` — DB 변경 이력
- `/docs/` — 디자인·개발 문서

기존 `/apps/` 주소는 새 `/tools/` 또는 `/guestbook/` 주소로 이동합니다.
