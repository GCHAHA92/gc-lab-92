# 금천 한끼 룰렛 — GitHub Pages MVP

## 설정

1. 카카오 디벨로퍼스에서 앱의 **JavaScript 키**를 확인합니다.
2. `config.js`의 `여기에_JAVASCRIPT_키를_입력하세요`를 실제 키로 바꿉니다.
3. 카카오 디벨로퍼스의 **플랫폼 > Web**에 GitHub Pages 주소를 등록합니다.
   - 예: `https://사용자명.github.io`
4. 이 폴더의 `index.html`, `styles.css`, `app.js`, `config.js`를 GitHub 저장소 루트에 올립니다.
5. GitHub 저장소의 **Settings > Pages > Deploy from a branch**에서 `main`과 `/ (root)`를 선택합니다.

키가 없거나 연결되지 않으면 데모 식당 데이터로 작동합니다.

## 이스터에그

룰렛을 돌릴 때마다 1% 확률로 세 슬롯이 모두 `퇴근해`에 멈춥니다.
